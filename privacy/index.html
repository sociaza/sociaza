1. Overview & Application Architecture

This Privacy Policy explains how Sociaza ("the Application", "we", "our", or "the software") handles data. Sociaza is an independent software application designed to help individual users organize, prepare, and manage publishing assets across social channels.

To maintain complete transparency with our users and platform API partners (including Pinterest and Etsy), this document details our technical architecture, current capabilities, and planned integrations:

  • Locally Hosted Execution: The Application is a locally hosted web application that runs directly on the user's personal computer and is accessed through a local web browser.
  • Single-User Scope: The Application is designed initially for one individual operator. It does not provide public multi-user accounts, shared hosted databases, or software-as-a-service (SaaS) multi-tenancy.
  • Zero Cloud Databases: User catalog data, settings, and credentials are stored strictly in a local database on the user's hard drive. No user data is transmitted to or hosted on Sociaza cloud servers.
Core Distinction: Current Operation vs. Planned Features

Currently, Sociaza operates as a local catalog and asset staging tool. While integrations with third-party publishing platforms (specifically Pinterest) are designed and under active development, live account publishing is not yet active, and real user account data from those platforms is not being ingested or processed at this time.

2. Categories of Information Processed

When operated by the user, the Application is designed to process only the specific categories of data necessary for its local cataloging and publishing workflow:

A. Local Workspace Configuration

User preferences, local file paths to image directories, application layout options, and publication schedule parameters selected within the local web application.

B. Etsy Shop & Catalog Information

When the user connects their Etsy shop using official authentication, the Application retrieves public and seller-facing catalog items via the official Etsy Open API v3:

  • Shop Metadata: Shop name, shop ID, and basic shop configuration.
  • Listing Data: Listing IDs, titles, descriptions, categories, pricing, item tags, and inventory status.
  • Listing Imagery: Public image URLs, image dimensions, and image asset files for cached display.

C. API Authentication Credentials

OAuth 2.0 access tokens and refresh tokens received directly from official platform authorization flows. These tokens allow the Application to execute authorized API calls on the user's explicit behalf.

3. Information We Explicitly Do Not Collect

Sociaza is architected with strict data minimization principles. The Application expressly does not collect, process, or store:

  • Customer & Buyer Information: The Application never requests, accesses, or downloads Etsy customer orders, buyer names, buyer delivery addresses, emails, or buyer payment records. API scopes for buyer or transaction data are intentionally omitted.
  • Financial & Payment Data: No credit card numbers, bank account numbers, or billing payment credentials are ever processed by Sociaza.
  • Tracking & Behavioral Telemetry: The local web application and this website do not include behavioral advertising trackers, session replay scripts, or third-party marketing SDKs.
  • Cross-User Data: Because the Application runs locally for a single user, no data from one user is ever mixed, aggregated, or co-mingled with any other user.

4. Third-Party API Integrations

Sociaza interacts exclusively with official platform APIs. We honor all platform developer terms, guidelines, and access restrictions.

Etsy Open API v3 (Operational — Read-Only)

Integration with Etsy is conducted strictly via the official Etsy Open API v3.

  • Authorized Scopes: Access is limited to read-only scopes necessary for catalog synchronization, specifically shops_r and listings_r.
  • Purpose: To allow the shop owner to inspect their existing listings, organize associated image files, and prepare publishing drafts without manual re-entry.
  • Storage: Synced catalog details are stored locally on the user's computer in a SQLite database file.
  • Attribution: The term 'Etsy' is a trademark of Etsy, Inc. Sociaza is an independent application and is not endorsed by or affiliated with Etsy, Inc.

Pinterest API v5 (In Development — Planned Integration)

The Application's planned Pinterest integration is currently under active development and has not yet been connected to real user accounts.

  • Intended Architecture: When completed, the Application is designed to use official Pinterest API v5 endpoints to read the user's available boards and create organic Pins from approved catalog drafts upon explicit user command.
  • OAuth Security: Pinterest OAuth access tokens and refresh tokens are designed to be stored locally on the user's device and encrypted at rest using the Application's existing local encryption mechanism.
  • Current Status: No real Pinterest account data is currently processed or stored. Live publishing will only commence following formal application review and approval under Pinterest's Developer terms.
  • Attribution: The term 'Pinterest' and the Pinterest logo are trademarks of Pinterest, Inc. Sociaza is an independent tool and is not endorsed by or affiliated with Pinterest, Inc.

5. Data Storage, Security & Boundaries

Because Sociaza is an independent, locally hosted web application running in a browser, data storage and security boundaries are established as follows:

  • Local SQLite Storage: Catalog data, cached asset metadata, draft pins, and publishing queues are saved in a local SQLite database file located in the application's local working directory.
  • Local Encryption at Rest: Sensitive API tokens and OAuth refresh secrets are designed to be stored in an encrypted state at rest using local cryptographic libraries.
  • No Central Cloud Server: There is no central Sociaza server, cloud synchronization cluster, or remote relational database holding user data. When the user interacts with an API, communication occurs directly between the local application instance and the respective platform endpoint (such as directly to api.etsy.com or api.pinterest.com).
  • Security Audit Status: The Application is developed with secure coding standards and modern cryptographic practices. However, to maintain honest disclosure, the Application has not undergone independent third-party commercial security audits. Users maintain physical and administrative security over their own computing environments.

6. User Control, Data Portability & Deletion

Because all application data is stored locally, users retain total control over their information at all times:

  • Local Data Removal: Users can permanently delete all stored catalog information, image caches, and settings by deleting the local SQLite database file or removing the local application directory.
  • Revocation of API Access:
    • Etsy: Users may revoke Sociaza's API access at any moment through their Etsy account under Account Settings > Apps.
    • Pinterest: Users may disconnect or revoke permissions at any time via their Pinterest profile under Settings > Apps.
  • Data Retention: Data remains on the user's local machine until the user deletes it, purges the local database, or clears the application cache. We do not retain backup copies because we do not operate remote storage infrastructure.

7. Multi-User & Public Service Limitations

To eliminate any ambiguity regarding our current service offering:

  • Sociaza does not currently offer public user registration, hosted user accounts, or web-based multi-user subscriptions.
  • Sociaza does not operate a public cloud software platform where multiple organizations or third parties share application instances.
  • Any future transitions toward multi-user or cloud-synchronized features will be accompanied by an updated Privacy Policy and explicit opt-in consent from users.

8. Changes to This Privacy Policy

As Sociaza evolves—particularly as Pinterest API v5 integration moves from private development into production status—we may update this Privacy Policy to reflect technical adjustments, new scopes, or regulatory standards.

Any revisions will be published immediately at https://sociaza.online/privacy/ with an updated effective date at the top of this document.
